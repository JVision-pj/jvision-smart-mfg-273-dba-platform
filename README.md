# 資料庫管理平台（DBA Platform）

> 服務工單、資產到即時監控的 IT 維運

資料庫管理平台（DBA Platform）提供資料庫效能監控與調校、慢查詢分析與索引建議、容量與儲存空間管理。資訊部依「資料庫納管→效能基準建立→持續監控與告警→問題調校優化→定期備份驗證→版本修補排程」推進作業，優先解決「資料庫效能瓶頸難以定位」，DBA團隊則以資料庫可用率與平均查詢響應時間確認成果。把散落的作業，整合成一個「可操作、可追蹤、可稽核」的單一平台。

**產業別：**資訊科技　|　**系統類型：**IT 維運管理平台

## 功能模組

- **服務工單** — 事件/請求工單管理
- **資產管理** — IT 資產與軟體授權
- **即時監控** — 系統/網路健康監控
- **告警事件** — 告警彙整與分派
- **變更發布** — 變更與發布管理
- **服務報表** — SLA 與可用率報表

## 適合誰使用

- DBA團隊
- 應用系統開發團隊
